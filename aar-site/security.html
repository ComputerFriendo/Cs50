Security

This site is designed to keep its attack surface small. It is not perfectly secure, and it is not a secure document system.

Architecture

  • Static files only (HTML, CSS, JavaScript and JavaScript data files), hosted on Neocities. No server-side code, database, uploads or user accounts.
  • All compiler processing happens in your browser. Projects are stored in your browser's localStorage and leave your device only when you export them.
  • No external libraries, CDNs, fonts, analytics or third-party scripts. Every script is a file on this site.

Threat model summary

ThreatHow the site respondsWhat remains
Malicious text pasted into fields (cross-site scripting)All text is inserted with text nodes only; the code never uses innerHTML, document.write, eval or new Function. The CSP blocks inline scripts and enforces Trusted Types.Browser bugs or extensions outside the site's control.
Malicious or malformed backup fileOnly .json under 2 MB; parsed with JSON.parse; nesting depth limited; rebuilt field by field from a fixed schema with type, length, ID and reference checks; unknown properties dropped; preview and confirmation before anything is replaced.A well-formed file with misleading but harmless text.
Dangerous linksUser-entered links must be https://; javascript:, data:, file:, vbscript: and malformed URLs are rejected. External links open with rel="noopener noreferrer". No URL is fetched automatically.A legitimate https site that is itself harmful.
Spreadsheet formula injection in CSV exportsCells beginning with = + - @ are prefixed with an apostrophe.None known.
Shared computer, other people or extensions reading dataWarnings before starting; no sensitive fields requested; contact details excluded from reports; one clearly named storage key; Reset deletes it.LocalStorage is not encrypted. Do not enter sensitive information.
Framing (clickjacking)Scripts hide the page and try to break out if it is loaded inside another site's frame.A header-based frame-ancestors policy cannot be set on Neocities (see below).
Data lossAutosave, manual save, storage error messages, JSON backup and restore.Clearing browser data deletes the project unless you have a backup.

Security headers on Neocities

Neocities does not let site owners set custom HTTP response headers. As a result:

  • Content-Security-Policy is delivered as a meta tag on every page: only this site's scripts and styles, no inline code, no network connections, no frames, no plugins, no form submission, and Trusted Types enforced.
  • frame-ancestors, Strict-Transport-Security, X-Content-Type-Options and Permissions-Policy cannot be set from a meta tag. Whether Neocities sends any of them by default has not been verified for this site. You can check in your browser's developer tools (Network tab, response headers).
  • Referrer-Policy is set to no-referrer with a meta tag.
  • HTTPS is provided by Neocities. All links on this site use https://.

Recommended practices for users

  • Enter only general, non-sensitive information. Refer to sensitive records by description and keep them in your organization's approved system.
  • Download a JSON backup after each working session and store it as you would any work document.
  • Avoid shared computers; if unavoidable, back up and reset before leaving.
  • Keep your browser up to date and limit extensions with access to all sites.
  • Confirm official documents on the agency's own website before relying on them.

Testing

Before publishing, the compiler was tested with script-like text, HTML tags, malicious-looking URLs and malformed or hostile backup files to confirm content stays inert. Testing covers this site only.

Reporting a problem

If you find a security problem, contact the site owner through their Neocities profile. Do not test against systems you do not own or have permission to test.
